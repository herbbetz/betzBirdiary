- SVG-Pfad auf 2 Nachkommastellen verkürzen, siehe `pathSimplify.html`
- Resize SVG to 32x32, siehe `pathResize.html`
- relative SVG Pfad Koordinaten (`c`, `l`) machen einen Overflow der 32x32 Viewbox, auch wenn alle Koordinatenzahlen unter 32 liegen. Dann muss mit `pathResize.html` wiederum der Faktor visuell ermittelt werden.
- Improve path position mit *Affinity3* (SVG klein). *Libreoffice Draw* erzeugt unschönen Code.
